# Overbuffed

A bullet-heaven roguelite starring buff. Survive the swarm, stack upgrades, get absurdly overbuffed.

Built with [debuff](https://debuff.jp) — and an open dogfooding project for it. Join us on [Discord](https://discord.gg/jshbDHSpCY).

```sh
npm install
npm run dev   # play
npm test      # logic tests + scenarios
```

- Code layout: `src/scenes/`, `src/systems/`, `src/content/` (enemies, weapons and upgrades as data).
- Art: see [ART.md](ART.md). Debuff issues found along the way: [FRICTION.md](FRICTION.md).
